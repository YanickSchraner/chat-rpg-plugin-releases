# Chat-RPG Auto Quest: releases

Signed builds of the Chat-RPG Auto Quest Firefox add-on. Only the builds are published here; the source is in a private repo.

**Install:** open the newest `.xpi` from [Releases](../../releases/latest) in Firefox and confirm.

**Updates:** Firefox checks [`updates.json`](updates.json) about once a day and installs new versions on its own (*about:addons* → gear → *Check for Updates* checks right away). Opening a newer `.xpi` by hand also upgrades in place and keeps your settings.
